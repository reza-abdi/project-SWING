# Changelog

## 1.0.0 — initial reconstructed release

This version identifies the repository's documented API metadata version (`1.0.0`) and initial simulator/decision-support release. It is not a claim that production deployment, public browser authentication, or every optional model artifact has passed runtime acceptance.

- IEEE 39/118 simulator API and browser dashboards.
- AI-assisted proposal and approval workflow with non-actuating chat and forecasts.
- Local-only defaults, bounded API requests, role-token checks, event persistence, and CI/browser test foundations.
- Optional single-host Docker Compose and Nginx TLS blueprint.
- Artifact provenance, configuration, operational limits, and deployment prerequisites documented.

Twin and Agent OpenAPI metadata currently report `1.0.0`; routes are not yet prefixed with a version segment. Breaking changes require an explicit API compatibility decision and updated contract documentation.
